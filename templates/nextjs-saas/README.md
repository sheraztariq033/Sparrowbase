# 🦜 SparrowBase Next.js 15 Full-Stack SaaS Starter

> Production-ready Next.js 15 App Router starter pre-wired with `@sparrowbase/react`.

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
# → http://localhost:3000
```

---

## 🏗️ Pre-built Features Included
- **Authentication**: Better-Auth sign in, sign up, and session persistence via `useSession()`.
- **Object Storage**: Direct streaming file uploads to Cloudflare R2 via `useFileUpload()`.
- **Workers AI Chat**: Token-streaming LLM assistant via `useAIChat()`.
- **Realtime WebSockets**: Multi-user collaboration & peer presence via `useRealtimeChannel()`.
