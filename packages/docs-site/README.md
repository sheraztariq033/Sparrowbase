# 🦜 `@sparrowbase/docs-site`

> Documentation Portal & Landing Web Application for SparrowBase (sparrowbase.dev)

Built with **Vite**, modern HTML5, CSS3, and JavaScript with interactive API testing playgrounds and code copy utilities.

---

## ⚡ Development

```bash
# Start Vite development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
