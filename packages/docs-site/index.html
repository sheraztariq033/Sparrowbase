SparrowBase Developer Documentation

1. Initializing a Project

Run the CLI scaffolder to set up Hono, D1, Better-Auth, and AI rules:

npx sparrowbase init my-app

2. Setting Up Cloudflare Resources ($0 Free Tier)

Authenticate once with Wrangler and provision D1 & R2:

npx wrangler login
npx wrangler d1 create sparrowbase-db
npx wrangler r2 bucket create sparrowbase-uploads

3. AI Vibe Coding Integration

Open the generated folder in Cursor, Windsurf, or v0. The embedded .sparrowbase/CLAUDE.md rulepack automatically enforces Cloudflare Workers edge compatibility.

4. Deploying to Cloudflare Pages & Workers

# Deploy Frontend to Cloudflare Pages
npx wrangler pages deploy packages/docs-site --project-name=sparrowbase

# Deploy Edge Backend Worker
npx wrangler deploy
